# Using GAN to prepare FastSim samples
## First, make a Geant4 like tree from GAN output (CSV file):
1. Run makeDumpParticlesFromGANLUXE.C
- Go inside root and run the following commands:
```
root -l
.L makeDumpParticlesFromGANLUXE.C++
makeDumpParticlesFromGANLUXE("<give the location and name of the CSV file generated by GAN>", "<give the output directory location where the Geant4 compatible tree will live>")
```

2. This will give a root tree which will be compatible with Geant4.


## Run the tree with Geant4

1. Copy this entire directory to your local area:
```
/srv01/agrp/arkas/Geant4_For_FastSim
```

2. Inside the `Geant4_For_FastSim`, look at `mc` subdirectory.
This contains text file having the location and the name of the root file generated from the GAN output. Create your own text file with the location and name of the root file from the GAN output.

3. Inside the `run_0` folder, in the `bashrunsim.sh` file, put the text file name along with the path in `mc_file_list` variable.

4. Then run the setup using:
```
source runsim.sh 1
```

The last number shows the runid: any unique integer.

5. This will create the `Geant4` tree.


## Analyze the tree generated by Geant4 in the previous step

1. Prepare the text file from the Geant4 tree. 
This text file will be used for making histograms to compare the FastSim and FullSim distribution

2. For this, use the code setup inside `Geant4FileProcessing` directory.

3. Put the output root file after the Geant4 processing in a text file. Suppose the name is `A.txt`.
4. In `runEBeamOnly.sh`, change the line:
```
filename="LUXEFastSim_PreparedFromPart2C.txt"
```
to
```
filename="A.txt"
```

5. In `process_track_tree_draw_v8.C`, write the `outDir` location.
This is the folder that will save the processed file in a text format.

6. Run this setup inside `Geant4FileProcessing`:
```
source runEBeamOnly.sh
```

7. The output will be a text file containing the track information at dump surface, as well as test surfaces.


## Prepare the histograms for comparison purpose
1. Use the code `makeLUXEFastSimFullSimDumpPlotsFromText.C`.

2. Run this inside the root prompt:
```
.L makeLUXEFastSimFullSimDumpPlotsFromText.C++
makeLUXEFastSimFullSimDumpPlotsFromText("<input text file string>", <detid integer>, 1.0, boolean to choose fullsim (true) or fastsim (false)) /// please see below for more explanation 
```

3. Here the first variable corresponds to the path and the text file name prepared in the previous step ("Analyze the tree generated by Geant4")

4. The second variable is an integer: 33 (for the dump surface), 32 (for the first test surface from the dump face), 31 (for the second test surface from the dump face)
5. The third variable represents the bunch crossing ID: here it is 1 because we are using first bunch crossing.
6. The fourth variable is a boolean: true to select FullSim and false for FastSim.


## Comparison of histograms between FastSim and FullSim
1. Once the histograms are prepared, then one needs to plot the 1D histograms of FullSim and FastSim.
2. Use the code `plotFastSimFullSim.py` here. 
3. Name a directory here: `outDir`. This is where the plots will be saved. If this directory does not exist, the code will create one.
4. Change the `inDir` to point to the path where your root files with histograms stay.
5. Change the `fullSimFile` and `fastSimFile` to point to your fullsim and fastsim files.
6. Run this code:
```
python plotFastSimFullSim.py -det <number>
```
7. Here `<number>` is 33 for the sampling plane, 32 for the first test surface from the dump and 31 for the second test surface from the dump.
